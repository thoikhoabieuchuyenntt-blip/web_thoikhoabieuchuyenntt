Quản trị & cập nhật thời khóa biểu

Tải tệp .xlsx, .xls hoặc .csv lên để cập nhật dữ liệu. Khi chạy GitHub Pages, thao tác này lưu dữ liệu ở trình duyệt đang sử dụng; để cập nhật cho tất cả người dùng, chủ web cần thay tệp dữ liệu trong kho GitHub hoặc kết nối thêm cơ sở dữ liệu.

Cột nên có: Ngày, Buổi, Tiết, Lớp, Môn, Giáo viên, Phòng. Có thể thêm cột Ghi chú.
