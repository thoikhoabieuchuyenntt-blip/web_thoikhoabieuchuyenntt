Cập nhật thời khóa biểu hằng tuần

Dùng nguyên file Excel của người xếp TKB, không cần sửa hay chuyển đổi. Web hiển thị đúng nội dung từng ô trong file.

  1. Chọn file TKB tuần mới (kéo thả vào ô bên dưới).
  2. Kiểm tra số lớp, ngày áp dụng và xem thử vài lớp.
  3. Bấm Công bố. Học sinh, phụ huynh thấy TKB mới sau 1–2 phút.
Kéo thả file Excel vào đây
hoặc bấm để chọn file (.xlsx, .xls)

Cài đặt kết nối GitHub

Web đọc dữ liệu trong thư mục data/ của kho GitHub. Để công bố TKB mới, dán mã truy cập (fine-grained token) chỉ có quyền Contents: Read and write trên kho này.

Logo trường

Chọn ảnh logo (PNG hoặc JPG, nên là ảnh vuông, nền trong suốt). Ảnh được chuyển thành assets/logo.png và hiện trên mọi trang.
